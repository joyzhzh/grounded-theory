**Authority:** no research, source acquisition, or dispatch authority issued

## Objective

Build the evidence base for the Grounded Theory method profile and operational
tool contract. The research must distinguish doctrine, empirical evaluation,
editorial/reporting practice, creator-authored tool claims, and researcher
inference.

## Evidence priorities

1. Foundational and later methodological texts for declared grounded-theory
   lineages.
2. Peer-reviewed methods work on constant comparison, memoing, theoretical
   sampling, negative cases, saturation/sufficiency, process research, and
   archival/digital-trace qualitative designs.
3. Empirical evaluations of CAQDAS, computational qualitative research, and
   LLM-assisted coding or analysis.
4. Official venue/editorial guidance relevant to management and organization
   research.
5. First-party tool/repository documentation only for bounded claims about
   documented functionality; independent evaluation is separate.

## Execution boundary

- Freeze a live `CHARTER.md`, lane catalog, schema, rubric, ask rows, routing
  profile, and external-vault root before query 1.
- Use Scout output only as discovery provenance.
- Each evidence-acquisition lane is one worker's exactly-ten-record handoff,
  `R001`–`R010`; the worker creates no `R011`. Work requiring more evidence
  becomes another separately authorized lane, never an extension of the same
  worker. The non-acquisition commander synthesis step is exempt.
- Preserve exact manifestations, hashes, quotes or explicit nulls, locators,
  rights/privacy state, contradictions, rivals, and source-stated scope.
- Keep `UNADJUDICATED`, admitted, accepted, released, and published distinct.
- The producing seat cannot adjudicate its own method synthesis or tool spec.

The proposed 16-lane executable catalog is
[GT-M01_LANE_CATALOG.md](GT-M01_LANE_CATALOG.md). It remains a draft until an
Operator architecture freeze.

## Proposed outputs

The mission returns a reviewed methods evidence package and a bounded method
recommendation. It does not run the AIGC study or modify the tool based on
unadjudicated findings.
